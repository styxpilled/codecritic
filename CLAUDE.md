This is codecritic - a Letterboxd-like webapp for rating npm packages. It uses Svelte/Kit, Drizzle, Cloudflare Workers, CF D1/SQLite. The UI is a cross between Letterboxd and One Dark Pro.

# Approach

- Use ASD-STE100 Simplified Technical English.
- Thorough in reasoning, concise in output.
- No sycophantic openers or closing fluff.
- Minimal, concise comments. Good code is self-documenting.
- No over-engineering.
- No em-dashes.
